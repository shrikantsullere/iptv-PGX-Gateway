# Project Overview
**PGX Gateway Frontend**

## What is PGX Gateway?
PGX Gateway is a state-of-the-art cryptocurrency payment processing frontend. It is designed to visually and functionally compete with tier-1 financial infrastructure providers. The platform abstracts away the complexity of blockchains, allowing standard web businesses to accept crypto just as easily as they accept credit cards via Stripe.

## The Frontend Implementation
This project is a fully-fleshed out React Single Page Application (SPA). It does not currently contain backend logic, but rather serves as a comprehensive, pixel-perfect blueprint of the entire system architecture from the user's perspective.

### Core Value Propositions Demonstrated in UI:
1. **Multi-Tenancy:** Distinct, powerful dashboards tailored specifically for the Merchant (the customer) and the Super Admin (the platform operator).
2. **Customizability:** The White Label Studio demonstrates how easily merchants can make the checkout experience their own.
3. **Advanced Data Visualization:** Heavy use of Recharts to transform raw blockchain and payment data into readable, actionable business intelligence.
4. **Luxury Aesthetics:** Dark mode, glassmorphism, subtle borders, and precise typography create trust and convey an "enterprise" feel.

## Tech Stack Overview
- **Core Framework:** React 18+
- **Build Tool:** Vite (for rapid HMR and optimized production builds)
- **Routing:** `react-router-dom` (v6+) handling SPA navigation.
- **Styling:** Tailwind CSS (utility-first, highly customized for dark mode).
- **Icons:** `lucide-react` (clean, consistent SVG iconography).
- **Charting:** `recharts` (composable React charting library).
- **Animations:** Standard CSS transitions and Tailwind `animate-in` utilities.
